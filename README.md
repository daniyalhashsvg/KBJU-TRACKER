# KBJU-TRACKER
KBJU Tracker — это обучающее веб-приложение, разработанное для того, чтобы помочь пользователю рассчитать ежедневную целевую норму каллорий. Приложение объединяет в себе калькулятор пищевой ценности, базу данных из 330 продуктов питания, автоматический расчет пищевой ценности по весу порции, а также дневник питания на каждый день.
